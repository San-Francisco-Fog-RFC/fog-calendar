How to subscribe

  1. iPhone / Mac: tap Subscribe above and accept. Updates arrive on their own.
  2. Google Calendar: tap Add to Google Calendar, or go to Other calendars → + → From URL and paste the link. Google refreshes every 12–24 h.
  3. Outlook: Add calendar → Subscribe from web → paste the link.

Developer & Syndication Feeds

To syndicate, scrape, or integrate SF Fog fixtures and club events into external websites, partner portals, search engines, or apps:

  • REST JSON API: events.json — Structured JSON feed with ISO-8601 timestamps and venue metadata.
  • iCalendar Feed: fog.ics — Standard RFC 5545 calendar feed for Apple, Google, and Outlook.
  • Schema.org JSON-LD: schema-events.jsonld — Google Events Rich Results payload for search indexing.
  • OpenAPI Specification: openapi.yaml — OpenAPI 3.1 contract for developers and aggregators.
