How to subscribe

  1. iPhone / Mac: tap Subscribe above and accept. Updates arrive on their own.
  2. Google Calendar: tap Add to Google Calendar, or go to Other calendars → + → From URL and paste the link. Google refreshes every 12–24 h.
  3. Outlook: Add calendar → Subscribe from web → paste the link.

Don't import the .ics file — that makes a one-off copy that never updates. Subscribe instead.
